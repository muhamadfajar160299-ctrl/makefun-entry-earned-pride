A single line about quiet, earned pride — the small daily win that no
one applauds — for the
[One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557)
competition on make.fun. Entries are judged blind, two at a time, by a
judge model that weighs the feeling first, then the turn, the tightness,
the freshness and the clarity.

## How it works

`main.py` (stdlib only) reads `entry.txt` sitting next to it and copies
it byte for byte to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`),
with mode `0644`. One direct write, no temp file, no rename — so the
grader can always read the output.

## Files

- `main.py` — the entrypoint
- `entry.txt` — the one-liner (109 characters, inside the 1–240 gate)
- `LICENSE` — MIT
